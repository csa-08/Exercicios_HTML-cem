Formatações

No HTML5, existe diferença entre sentido(HTML) e a forma(CSS).

tags como <b> para negrito ou <i> para itálico são relacionados à forma, diferente das tags <strong> e <em> são relacionados ao sentido do texto.

Exemplos:

Negrito:

Frase com uma palavra em negrito com a tag <b> (não emântico)

Frase com uma palavra em negrito com a tag <strong> (semântico)

Itálico

Frase com uma palavra em itálico com a tag <i> (não semântico)

Frase com uma palavra em itálico com a tag <em>

texto marcado:

Marcação de texto com a ta <mark>

obs: Para mudar a cor do marcador, usar o parâmetro style.

Tamanho do texto:

Para aumentar o tamanho das letras, pode-se usar a tag <big>, porém não é recomendado, pois ela é uma tag obsoleta.

Para diminuir o tamanho, usar a tag <small> (diferente da tag <big>).

Texto deletado e inserido:

Para riscar o texto, usar a tag <del>.

Para sublinhar, usar a tag <ins>.

Texto subscrito e sobrescrito

Para sobrescrever um texto, use a tag <sup> (a2 + b2)

Para subscrever um texto, use a tag <sob> (H2O)
