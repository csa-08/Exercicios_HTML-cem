Parâmetros


content Retorna o valor relacionado ao atributo http ou name

lang Determina a língua do elemento

rel Indica a relação entre o documento e o documento linkado

charset Especifica a codificação dos caracteres

src Especifica a URL

alt Exibe um texto alternativo caso o original não puder ser carregado

target Indica onde abrir o documento linkado ou onde enviar um formulário

type Indica o tipo do elemento

style Adiciona um elemento CSS

start Indica aonde uma lista ordenada começa

name Determina o nome do elemento

dowload Indica que o arquivo de um link pode ser baixado

media Indica para qual mídia ou dispositivo o documento está otimizado

srcset Indica a URL da imagem a ser utilizada em diferentes situações

controls Adiciona controles ao audio ou vídeo na página
